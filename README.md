## ⚙️ How to Run Locally

   ```bash

2. **Navigate to the source folder**
   ```bash
   cd hackerrank-java-solutions/src
   
3. **Compile and run any Java file**
  ```bash
  javac Q01_Java_Stdin_Stdout.java
  java Q01_Java_Stdin_Stdout
